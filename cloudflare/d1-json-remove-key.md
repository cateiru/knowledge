# D1（SQLite）の JSON 列から、特定のキーだけを外す

## やりたいこと

`{ "<id>": [...], ... }` のように ID をキーにした JSON を 1 列に持つテーブルで、ある ID のキーだけを、すべての行からまとめて外したい。たとえば、対象が使えなくなったときに、その ID に付けていた許可を外す。

## 方法

SQLite の JSON 関数を使う。D1 でも使える。

- キーを外す: `json_remove(col, '$."<key>"')`
- キーがあるか: `json_type(col, '$."<key>"') IS NOT NULL`

キーに `-` などを含むことがあるため、パスはキーを `"` で囲んで書く。

drizzle-orm では次のように書いた。パスはバインドパラメーターとして渡す。

```ts
const keyPath = `$."${id}"`;
db.update(table)
  .set({ jsonColumn: sql`json_remove(${table.jsonColumn}, ${keyPath})` })
  .where(isNotNull(sql`json_type(${table.jsonColumn}, ${keyPath})`));
```

`WHERE` でキーがある行だけに絞ると、関係のない行の更新日時などを書き換えずに済む。

## 確かめたこと

- 2026年11月に、sql.js（drizzle-orm の `sql-js` ドライバー）を使った Vitest のテストで、ほかのキーを残して対象のキーだけが外れることを確かめた。sql.js の標準のビルドで JSON 関数が使える。
- 外したあとに中身が空になった行は `{}` になる（行は消えない）。

## 注意

- キーの文字列をパスに埋め込むため、`"` や `\` を含みうる値をキーにする場合はエスケープが必要になる。UUID のように使う文字が決まっている ID なら、そのまま囲めばよい。
- ほかの書き込みと同時に、条件付きで実行したいとき（たとえば「対象の状態が変わったときだけ外す」）は、`EXISTS (...)` の条件を `WHERE` に加えて、D1 の batch の同じトランザクションに並べる。
