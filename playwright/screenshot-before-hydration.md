# ハイドレーション前にスクリーンショットを撮ると、Next.js の「Issue」が出る

2026年11月に、Playwright 1.65 と Next.js 16（`next dev`）で見たもの。

## 起きたこと

`page.goto()` の直後に `page.screenshot()` を撮ってから操作を続けると、Next.js の開発用の表示に「1 Issue」が出た。中身はハイドレーションの不一致で、チェックボックスの `input` の `style` に、サーバーの HTML にはない `caret-color: transparent` が付いていると報告された。

同じページを、スクリーンショットを撮らずに開いて数秒待ったときは出なかった。

## 原因の見立て

Playwright の `screenshot()` は、既定（`caret: "hide"`）でテキストのキャレットを隠す。ハイドレーションが終わる前に撮ると、そのためのスタイルがハイドレーション中の DOM に残り、React が不一致として報告したものと考えている（Playwright の実装までは確かめていない）。

アプリの不具合ではないので、確かめるときは次のどちらかにする。

- 撮る前に、ハイドレーションが終わるのを待つ（見出しなどが操作できるようになるのを待つ、少し待つ）
- 不一致が出たら、スクリーンショットを撮らずに同じページを開いて、出ないことを確かめる
