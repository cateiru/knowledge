# 操作の列をなくした表で、日本語の列が 1 文字ずつ折り返す

2026年11月に、管理画面の一覧の表から操作の列（フォーム・ボタン）を外したところ、スマートフォンの幅（390px）で名前の列が 1 文字ずつ折り返して読めなくなった。

## 何が起きたか

表は `width: 100%` で、狭い画面では親の `overflow-x: auto` で横にスクロールさせる作りだった。

- 操作の列があったときは、ボタンや `white-space: nowrap` の入力欄が表の最小の幅を押し広げていたので、表は画面より広くなり、横にスクロールしていた
- 操作の列を外すと、どの列も折り返せる中身だけになる。日本語は文字と文字の間で折り返せるので、各列の最小の幅（min-content）は 1 文字分まで小さくなる
- その結果、表が画面の幅に収まるように列が縮み、名前の列が 1 文字ずつ折り返した
- ID などに `overflow-wrap: anywhere` を付けていると、英数字の長い文字列も最小の幅の計算で折り返せる扱いになり、さらに縮む

## 対処

名前・所属などの文字の列に最小の幅を付けた。収まらないときは、これまでどおり表が横にスクロールする。

```css
/* 名前・所属などの文字の列 */
.textColumn {
  min-width: 10rem;
}
```

```tsx
<th scope="row" className={styles.textColumn}>...</th>
<td className={styles.textColumn}>...</td>
```

列ごとに `white-space: nowrap` にする方法もあるが、長い名前や UUID の ID が 1 行に伸びて表が横に長くなりすぎるので、最小の幅にした。

## 気づき方

表から列を外す・ボタンを文字に置き換えるなど、表の中身を折り返せるものだけにする変更では、狭い画面の幅でも見た目を確かめる。広い画面では変化がないので気づきにくい。
